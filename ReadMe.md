## ✨ Temel Özellikler

* **Öğrenci ve Ders Kayıtları:** Yeni öğrenci ve ders bilgilerinin sisteme eklenmesini ve güncellenmesini sağlar.
* **Not Girişi ve Yönetimi:** Öğrencilerin vize, final veya diğer sınav notlarının kolayca sisteme girilmesini ve yönetilmesini destekler.
* **Başarı Durumu Hesaplama:** Girilen notlara göre öğrencinin ders başarı ortalamasını ve geçme/kalma durumunu hesaplar.
* **Veritabanı Entegrasyonu:** Tüm öğrenci, ders ve not bilgilerini kalıcı olarak depolamak için bir veritabanı (örneğin SQL Server) kullanır.
* **Form Tabanlı Arayüz:** Öğretmenlerin veya yöneticilerin veri girişini ve görüntülemesini kolaylaştıran kullanıcı dostu bir Windows Form (Form Application) arayüzüne sahiptir.
* **Geliştirme Dili:** Uygulama, **C#** programlama dili ile geliştirilmiştir.

## 💻 About the Project

---

## ✨ Core Features

* **Student and Course Records:** Allows for the addition and updating of new student and course information into the system.
* **Grade Entry and Management:** Supports easy entry and management of student grades from midterm, final, or other exams.
* **Success Status Calculation:** Calculates the student's course success average and determines the pass/fail status based on the entered grades.
* **Database Integration:** Uses a database (e.g., SQL Server) to permanently store all student, course, and grade information.
* **Form-Based Interface:** Features a user-friendly Windows Form Application interface to facilitate data entry and viewing for teachers or administrators.
* **Development Language:** The application is developed using the **C#** programming language.
